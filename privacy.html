Política de Privacidade

Última atualização: 28 de setembro de 2026.

1. Finalidade

FBC Integrations é uma estrutura privada de integração com APIs e serviços de terceiros. O objetivo é consultar e organizar informações autorizadas relacionadas a produtos, vendas, afiliados, métricas e dados financeiros.

2. Dados e credenciais

Este site público não coleta senhas, tokens, chaves de API ou outras credenciais. Credenciais necessárias às integrações são mantidas em ambiente privado e não são publicadas neste repositório ou nesta página.

3. Acesso por API

Quando uma plataforma autoriza uma integração, somente os escopos concedidos pelo titular são utilizados. A arquitetura prioriza acesso de leitura e o princípio de menor privilégio.

4. Compartilhamento

Dados obtidos por integrações autorizadas não são vendidos. O uso fica restrito às finalidades operacionais autorizadas pelo titular das contas e às obrigações aplicáveis.

5. Segurança

Segredos e tokens são mantidos fora de páginas públicas. Integrações são separadas por escopo e submetidas a controles de acesso e validação.
